# LLD & Machine Coding Interview Masterclass

> A step-by-step topological roadmap from foundational principles to advanced real-world problem-solving.

## Roadmap Overview

```
Phase 1: Foundational Prerequisites
    ├── OOP (Abstraction, Polymorphism, Inheritance, Composition)
    ├── SOLID Principles
    └── Dependency Injection

Phase 2: Intermediate Design Patterns
    ├── Must-Know: Strategy, Iterator, Builder, Factory, Adapter, Observer, CoR, State
    └── Secondary: Singleton, Decorator, Proxy, Criteria

Phase 3: Advanced Machine Coding Problems
    ├── State-driven: Elevator, ATM
    ├── Payment/Action: Parking Lot
    ├── Concurrency: BookMyShow, E-commerce
    ├── Infrastructure: KV Store, Distributed Queue, Logger, Vending Machine
    └── Games: Tic-Tac-Toe, Chess, Card Games

Phase 4: Engineering Practices
    ├── Concurrency (Threads, Locks)
    └── Software Testing
```

## How to Use This Guide

1. **Follow phases sequentially** — each builds on the previous
2. **Don't memorize — understand trade-offs** — ask why, not just what
3. **Practice 10-20 core problems 2-3 times each** with different pattern combinations
4. **Java recommended** — most resources and references use it

## Quick Reference

| Phase | Focus | Time Estimate | Key Outcome |
|-------|-------|---------------|-------------|
| 1 | Foundations | 1-2 weeks | Identify SOLID violations, choose composition over inheritance |
| 2 | Patterns | 2-3 weeks | Map problems to Strategy/Builder/Observer naturally |
| 3 | Machine Coding | 3-4 weeks | Build production-quality systems in 45-60 min |
| 4 | Engineering | 1 week | Write thread-safe, tested code under pressure |
